# Well-being Reminder App ⏰

A simple web application for maintaining healthy habits with personalized reminders for movement breaks, meals, hydration, and other activities.

## Project Overview 📜

This project was created as a **recruitment task** to demonstrate frontend development skills. It's a **Reminder App** that reminds users to stand up, stretch, drink water, or take care of other wellness activities at customizable intervals.

### Key Features 🌟

- Reminders with customizable intervals,
- "Do Not Disturb" hours,
- Real-time upcoming reminders display,
- Form validation and error/success alerts,
- All reminders saved in browser's LocalStorage.

## Technologies Used 🚀

- **Angular** with **TypeScript**,
- **CSS** for styling,
- GitHub Pages for deployment.
