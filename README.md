# Well-being Reminder App ⏰

A simple web application for maintaining healthy habits with personalized reminders for movement breaks, meals, hydration, and other activities.

## Project Overview 📜

This project was created as a **recruitment task** to demonstrate frontend development skills. It's a **Reminder App** that alerts the user to stand up, stretch, drink water, or take care of other wellness activities at customizable intervals.

### Key Features 🌟

- Reminders with customizable intervals,
- "Do Not Disturb" hours,
- Real-time upcoming reminders display,
- Form validation and error/success alerts,
- All reminders saved in browser's LocalStorage.

## Technologies Used 🚀

- **Angular** with **TypeScript**,
- **CSS** for styling,
- GitHub Pages for deployment.

# Aplikacja Przypominająca o Dobrym Samopoczuciu ⏰

Prosta aplikacja webowa wspierająca zdrowe nawyki dzięki spersonalizowanym przypomnieniom o przerwach na ruch, posiłkach, nawodnieniu oraz innych aktywnościach.

## Opis projektu 📜

Projekt został stworzony jako **zadanie rekrutacyjne**, aby zaprezentować umiejętności frontendowe. Jest to Aplikacja ma na celu przypominanie użytkownikowi o konieczności wstania, rozciągnięcia się, wypicia wody lub zadbania o inne aspekty dobrego samopoczucia w wybranych odstępach czasu lub o wybranych godzinach.

### Kluczowe funkcje 🌟

- Przypomnienia z możliwością dostosowania interwałów,
- Możliwość dodania funkcji „Nie przeszkadzać”,
- Podgląd nadchodzących przypomnień w czasie rzeczywistym,
- Walidacja formularzy i komunikaty błędów/sukcesów,
- Wszystkie przypomnienia zapisywane w LocalStorage przeglądarki.

## Wykorzystane technologie 🚀

- **Angular** z **TypeScript**,
- **CSS**,
- GitHub Pages.
